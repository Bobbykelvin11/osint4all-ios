# OSINT4ALL for iOS

An unsigned SwiftUI iOS app (iOS 16+) for [OSINT4ALL](https://start.me/p/L1rEYQ/osint4all) ([`osint4all/osint4all.github.io`](https://github.com/osint4all/osint4all.github.io)).

## Features
- **Offline Directory**: Bundles 77 categories and 1,459 OSINT tool links in `links.json` for fast offline browsing and search.
- **Favorites**: Star tools to save them locally for instant access.
- **In-App Browser**: Tool links open in `SFSafariViewController`.
- **Live start.me Tab**: Embedded `WKWebView` with Back, Forward, Reload, and pull-to-refresh for the live start.me dashboard.
